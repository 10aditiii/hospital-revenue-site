Hospital Network Revenue - how to run in VS Code

1. Unzip this folder and open it in VS Code (File > Open Folder).
2. Easiest: install the "Live Server" extension, right-click index.html and choose "Open with Live Server".
   Or just double-click index.html to open it in your browser - no server is needed.

Files
- index.html : page structure
- styles.css : look and layout (light and dark mode)
- data.js    : all the numbers (countries, hospitals, costs, 12 monthly revenue amounts)
- script.js  : builds the page and handles the clicks

To change the numbers, edit data.js. Each hospital's "monthly" list should add up to its "revenue".
